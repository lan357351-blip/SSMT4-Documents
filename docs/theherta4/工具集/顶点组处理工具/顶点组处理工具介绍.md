# 顶点组处理工具

顶点组处理工具提供了一系列用于管理 Blender 物体顶点组的功能，包括顶点组的创建、重命名、清理、备份恢复和权重调整。

## 功能列表

### 顶点组重命名与骨骼

| 功能 | 说明 |
|------|------|
| 用模型名称作为前缀重命名顶点组 | 将选中物体的所有顶点组名称添加"模型名_"前缀 |
| 根据顶点组生成基础骨骼 | 为每个顶点组创建一根默认位置的骨骼 |

### 顶点组创建与清理

| 功能 | 说明 |
|------|------|
| 创建组和UV | 创建指定名称的满权重/空权重顶点组，并自动创建UV层 |
| 批量重命名 | 将所有选中物体中指定名称的顶点组重命名 |
| 批量删除 | 按名称列表批量删除顶点组 |
| 执行清理 | 删除零权重顶点组和指定名称的顶点组 |

### 数字格式化工具

| 功能 | 说明 |
|------|------|
| 按数字前缀合并 | 将相同数字前缀的顶点组合并为一个，可选同步合并骨骼 |
| 仅保留数字顶点组 | 删除所有名称不是纯数字的顶点组 |
| 填充顶点组数字空隙 | 在数字序列中补齐缺失的顶点组 |

### 权重备份与恢复

| 功能 | 说明 |
|------|------|
| 备份顶点组权重 | 将当前物体的所有顶点组权重数据序列化为JSON保存 |
| 恢复顶点组权重 | 从备份中恢复顶点组权重数据 |
| 批量备份/恢复 | 对所有选中物体执行备份或恢复操作 |

### 权重调整

| 功能 | 说明 |
|------|------|
| 调整权重 | 对勾选的顶点组按加法或乘法模式调整权重 |
| 规格化权重 | 将选中顶点组或所有顶点组的权重归一化 |
