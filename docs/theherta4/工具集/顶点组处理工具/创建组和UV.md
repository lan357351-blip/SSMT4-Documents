# 创建组和UV

## 功能说明

为所有选中的网格物体批量创建顶点组和UV层。

## 参数

| 参数 | 说明 |
|------|------|
| 满权重组名称 | 创建一个所有顶点权重为1.0的顶点组 |
| 空权重组名称 | 创建一个所有顶点权重为0的顶点组 |
| 删除已有顶点组 | 开启后先清除所有现有顶点组再创建 |

## 执行的操作

1. 遍历所有选中的网格物体
2. 如果启用了"删除已有顶点组"，先清除所有现有顶点组
3. 创建指定名称的满权重顶点组（所有顶点权重1.0）
4. 创建指定名称的空权重顶点组（所有顶点权重0）
5. 如果物体没有UV层，自动创建一个名为 `UVMap` 的UV层

## 效果

- 每个选中物体新增两个顶点组（满权重和空权重）
- 没有UV的物体会自动获得一个默认UV层
