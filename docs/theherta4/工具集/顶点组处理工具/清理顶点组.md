# 清理顶点组

## 功能说明

清理选中物体的顶点组，删除零权重顶点组和指定名称的顶点组。

## 参数

| 参数 | 说明 |
|------|------|
| 清理名称列表 | 逗号分隔的顶点组名称，匹配的顶点组将被删除 |
| 移除零权重 | 开启后删除总权重接近零的顶点组 |

## 执行的操作

1. 如果启用了零权重清理：
   - 删除名称匹配指定列表的顶点组
   - 计算每个顶点组的总权重，删除总权重接近零的顶点组
2. 如果未启用零权重清理：
   - 直接清除所有顶点组

## 效果

- 无用的零权重顶点组被移除
- 指定名称的顶点组被移除
- 顶点组列表更加整洁
