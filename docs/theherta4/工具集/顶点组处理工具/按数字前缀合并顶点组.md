# 按数字前缀合并顶点组

## 功能说明

将名称中具有相同数字前缀的顶点组合并为一个顶点组。合并时权重累加（上限1.0），非数字名称的源顶点组将被删除。

## 参数

| 参数 | 说明 |
|------|------|
| 同步合并骨骼 | 开启后，同时合并骨架中对应名称的骨骼 |

## 执行的操作

1. 提取每个顶点组名称的数字前缀
2. 按数字前缀分组
3. 同组内的顶点组合并为一个，权重累加（不超过1.0）
4. 删除非数字名称的源顶点组
5. 如果启用了同步合并骨骼，对骨架中的骨骼执行相同的合并操作

## 效果

- 相同数字前缀的顶点组被合并
- 非数字名称的顶点组被删除
- 骨骼同步合并（可选）

## 适用场景

- 游戏模型中骨骼索引需要合并时（如左右对称骨骼共用一个索引）
