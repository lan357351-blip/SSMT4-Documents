# 权重调整与规格化

## 功能说明

对选中物体的顶点组权重进行调整和规格化操作。

## 权重调整

### 参数

| 参数 | 说明 |
|------|------|
| 调整量 | 权重调整的数值 |
| 调整模式 | 加法（在当前权重上加减）或乘法（乘以系数） |

### 执行的操作

1. 从可用列表中选择要调整的顶点组
2. 对选中顶点组的所有顶点权重执行加法或乘法运算
3. 权重值钳位在 0~1 范围内

## 权重规格化

### 参数

| 参数 | 说明 |
|------|------|
| 规格化模式 | 仅选中组（选中组权重之和+其他组权重之和=1）或全部组（每顶点总权重=1） |

### 执行的操作

- **选中组模式**：仅规格化选中的顶点组，使选中组权重之和与其他组权重之和归一化为1
- **全部组模式**：规格化所有顶点组，使每个顶点的总权重等于1

## 效果

- 权重调整后可以精确控制顶点组的权重分布
- 规格化后权重分布更加合理，避免权重溢出
