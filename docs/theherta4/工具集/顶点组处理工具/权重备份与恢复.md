# 权重备份与恢复

## 功能说明

对网格物体的顶点组权重数据进行备份和恢复，支持单物体和批量操作。

## 备份操作

1. 遍历活动物体的所有顶点
2. 收集每个顶点的顶点组索引和权重值（忽略小于1e-6的微小权重）
3. 将组映射和顶点权重数据序列化为JSON
4. 存入物体的 `vg_backups` 集合属性中

## 恢复操作

1. 从当前选中的备份项读取JSON数据
2. 先删除物体所有现有顶点组
3. 按备份数据重建顶点组
4. 逐顶点恢复权重值

## 批量操作

- **批量备份**：对所有选中的网格物体逐一执行备份，跳过无顶点组的物体
- **批量恢复**：对所有选中的网格物体，从其第一个备份项恢复权重

## 效果

- 备份后可以安全地进行权重编辑操作
- 恢复时完全还原到备份时的权重状态
- 支持多个备份版本，可选择性恢复
