# 根据顶点组生成基础骨骼

## 功能说明

根据选中网格物体的顶点组列表，自动创建一个骨架（Armature）物体，为每个顶点组生成一根骨骼。骨骼的默认位置为世界原点。

## 执行的操作

1. 获取选中网格物体的所有顶点组名称
2. 创建新的骨架物体，命名为 `{网格名}_Armature`
3. 进入编辑模式，为每个顶点组创建一根骨骼
4. 骨骼名称与顶点组名称一致
5. 将骨架设为网格物体的父级（使用骨架绑定）

## 效果

- 场景中新增一个骨架物体
- 骨架中的每根骨骼对应一个顶点组
- 网格物体自动绑定到该骨架

## 适用场景

- 需要快速为已有顶点组的模型创建骨架
- 从其他软件导入的模型只有顶点组没有骨骼时
