# 形态键动画序列导出

导出选中物体的形态键动画序列，生成播放表并输出到文本编辑器。

## 参数

| 参数 | 说明 |
|------|------|
| 起始帧 | 采样的起始帧 |
| 结束帧 | 采样的结束帧 |

## 执行的操作

1. 在指定帧范围内逐帧采样
2. 对每帧记录所有选中物体的形态键值
3. 生成播放表格式：`形态键名 = 值1,值2,值3,...`
4. 输出到Blender内置文本编辑器

## 输出格式示例

```
Key_发 = 0.5,0.25,1,0.68,0.6,0.7
Key_脸 = 0.0,0.3,0.5,0.8,1.0,0.5
```

## 效果

- 生成形态键动画的数值播放表
- 可用于游戏引擎中的形态键动画驱动
