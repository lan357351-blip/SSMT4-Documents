# 形状差异与帧拆分

## 形状差异转形态键

选择两个顶点数相同的物体，将第二个物体（目标形状）的世界坐标转换到第一个物体（基础物体）的局部空间，写入为形态键。

### 参数

| 参数 | 说明 |
|------|------|
| 形态键名称 | 新形态键的名称 |

### 执行的操作

1. 验证两个物体顶点数相同
2. 计算目标物体顶点的世界坐标
3. 将世界坐标转换到基础物体的局部空间
4. 在基础物体上创建新形态键并写入坐标

### 效果

- 基础物体获得一个新的形态键
- 形态键的形状与目标物体一致

## 多物体拆分帧到形态键（增强版）

使用模态状态机异步处理，为每个选中物体和每个帧/形态键对创建形态键。

### 参数

| 参数 | 说明 |
|------|------|
| 帧/形态键对列表 | 每对指定一个帧号和对应的形态键名称 |
| 起始帧 | 动画的起始帧 |
| 高精度模式 | 逐帧跳转确保动画准确性 |
| 连续模式 | 前一帧的结束作为下一帧的起始基础 |

### 执行的操作

1. 为每个选中物体和每个帧/形态键对：
   - 在目标帧创建快照物体
   - 基于起始帧和结束帧物体的形状差异创建形态键
2. 连续模式下，前一帧的结束作为下一帧的起始基础
3. 将中间物体的形态键复制回原始物体
4. 清理临时数据

### 效果

- 每个物体获得按帧拆分的形态键序列
- 可用于将动画转换为形态键数据
