# 动画帧拆分

将选中物体在指定帧范围内的每一帧拆分为独立静态网格物体。

## 参数

| 参数 | 说明 |
|------|------|
| 新物体名称前缀 | 拆分后物体的名称前缀 |
| 子集合前缀 | 存放拆分物体的子集合前缀 |
| 起始帧/结束帧 | 拆分的帧范围 |
| 播放类型 | 拆分物体的播放类型标记 |
| 分离静态部分 | 分析动画中不变的顶点，将静态和动态部分分离 |
| 静态容差 | 判断顶点是否为静态的位移容差 |
| 线性插值 | 将关键帧插值设为线性，防止过冲 |

## 执行的操作

1. 在指定帧范围内逐帧遍历
2. 每帧创建物体的快照（静态网格副本）
3. 如果启用了静态分离：
   - 分析动画中哪些顶点始终不动
   - 按面完整性扩展动态区域
   - 将静态和动态部分分离为不同物体
4. 可选将关键帧插值设为线性
5. 拆分后的物体放入源集合下的子集合中

## 效果

- 每一帧的动画姿态被保存为独立物体
- 静态和动态部分可以分离处理
- 适用于将骨骼动画转换为逐帧模型
