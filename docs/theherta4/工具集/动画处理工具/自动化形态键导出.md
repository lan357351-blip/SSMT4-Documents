# 自动化形态键导出

依赖SSMT的自动化形态键导出流水线。

## 参数

| 参数 | 说明 |
|------|------|
| 节点树名称 | SSMT蓝图节点树的名称 |
| 导出基础路径 | 导出文件的根目录 |
| 步进延时 | 每步操作之间的延时（秒） |
| 最终延时 | 全部完成后的延时（秒） |

## 执行的操作

1. 从SSMT节点树收集目标物体
2. 清理损坏的形态键
3. 分类并输出形态键报告到文本编辑器
4. 导出基础形态（所有形态键归零，调用SSMT导出，重命名Buffer为Buffer0000）
5. 逐个槽位激活形态键（值设1.0）并导出，重命名Buffer为Buffer1xxx
6. 最终将所有形态键归零

## 效果

- 自动完成形态键的导出流程
- 每个形态键槽位生成独立的Buffer文件
- 形态键分类报告输出到文本编辑器
