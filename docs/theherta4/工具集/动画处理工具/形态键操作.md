# 形态键操作

提供形态键的批量管理功能。

## 批量添加形态键

为所有选中网格物体添加指定名称的新形态键。若无Basis则先创建，跳过已存在同名键的物体。

### 参数

| 参数 | 说明 |
|------|------|
| 形态键名称 | 要添加的形态键名称 |

## 批量删除形态键

从所有选中网格物体中删除指定名称的形态键（禁止删除Basis）。

## 归零所有形态键

将所有选中物体的所有非Basis形态键值设为0。

## 设置活动形态键

将指定名称的形态键设为所有选中物体的活动形态键。

### 参数

| 参数 | 说明 |
|------|------|
| 形态键名称 | 要设为活动的形态键名称 |

## 批量重命名形态键

将选中物体中指定名称的形态键批量重命名为新名称，跳过已存在同名键的物体。

### 参数

| 参数 | 说明 |
|------|------|
| 原名称 | 需要重命名的形态键名称 |
| 新名称 | 重命名后的名称 |
