# 形态键统一控制器

统一控制多个物体的形态键值，提供跨物体的形态键同步管理。

## 功能说明

### 刷新列表

扫描所有选中网格物体的形态键，收集所有非Basis的唯一形态键名称，排序后生成统一的控制列表，并读取第一个包含该键的物体的当前值。

### 复制形态键到选中项

将活动物体的所有形态键的相对位移（delta = 形态键坐标 - Basis坐标）复制到其他顶点数相同的选中物体。

#### 参数

| 参数 | 说明 |
|------|------|
| 使用手动旋转 | 开启后使用手动指定的旋转矩阵来转换delta |
| 旋转X/Y/Z | 手动旋转的欧拉角（度） |

#### 执行的操作

1. 计算活动物体每个形态键的delta（形态键坐标 - Basis坐标）
2. 如果启用手动旋转，使用指定的旋转矩阵转换delta
3. 否则自动从物体的世界矩阵计算变换矩阵
4. 将转换后的delta应用到其他选中物体的对应形态键

## 效果

- 多个物体的形态键值可以统一调整
- 形态键数据可以在不同物体间复制
