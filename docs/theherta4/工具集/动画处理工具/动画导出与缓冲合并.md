# 动画导出与缓冲合并

## 动画导出（ZZZ）

在指定帧范围内逐帧导出骨架的Pose Bone矩阵数据为.buf文件。

### 参数

| 参数 | 说明 |
|------|------|
| 导出骨架 | 是否导出骨架数据 |
| 导出网格 | 是否导出网格数据 |
| 导出路径 | 输出文件路径 |
| 起始帧/结束帧 | 导出的帧范围 |
| 地面偏移 | Y轴的地面偏移量 |

### 执行的操作

1. 在指定帧范围内逐帧设置场景帧
2. 读取骨架的Pose Bone矩阵（3x4）
3. 按顶点组匹配顺序将矩阵数据以float32二进制格式写入.buf文件

### 效果

- 生成包含骨骼动画数据的.buf文件
- 适用于绝区零（ZZZ）的动画导出

## 顶点缓冲合并

将分离的Position和Texcoord缓冲文件合并为单个.buf文件。

### 参数

| 参数 | 说明 |
|------|------|
| 缓冲路径 | 包含.buf文件的文件夹路径 |

### 执行的操作

1. 扫描指定文件夹中所有`*-Position.buf`文件
2. 查找对应的`*-Texcoord.buf`文件
3. 将每对文件按顶点逐个交错合并（16字节Position + 8字节Texcoord = 24字节/顶点）
4. 输出为`*.buf`

### 效果

- 分离的顶点数据被合并为单个文件
- 每个顶点24字节（Position 16B + Texcoord 8B）
