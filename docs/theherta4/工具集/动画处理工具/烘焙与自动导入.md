# 烘焙与自动导入（Alembic）

将选中物体导出为Alembic(.abc)文件，然后自动导入该文件。

## 参数

| 参数 | 说明 |
|------|------|
| 导出文件夹 | Alembic文件的输出目录名 |
| 导入集合 | 导入物体放置的目标集合名 |
| 缩放系数 | Alembic导出的缩放系数 |
| 导出UV | 是否导出UV数据 |
| 传递顶点组 | 单物体时，通过拓扑映射传递顶点组权重 |

## 执行的操作

1. 验证文件已保存且有选中物体
2. 将选中物体导出为Alembic(.abc)文件
3. 自动导入该Alembic文件
4. 将导入的物体放入指定集合
5. 如果是单物体且启用了顶点组传递，通过拓扑映射将原始物体的顶点组权重传递到导入物体

## 效果

- 动画数据被"烘焙"为Alembic格式
- 导入的物体包含完整的动画帧数据
- 可选保留顶点组权重信息
