# 动画处理工具

动画处理工具（ATP）提供了形态键控制、Alembic烘焙导入、动画帧拆分和自动化导出等功能。

## 子面板列表

| 面板 | 说明 |
|------|------|
| [形态键统一控制器](/theherta4/工具集/动画处理工具/形态键统一控制器) | 统一控制多个物体的形态键值 |
| [形态键操作](/theherta4/工具集/动画处理工具/形态键操作) | 批量添加/删除/重命名/归零形态键 |
| [形状差异与帧拆分](/theherta4/工具集/动画处理工具/形状差异与帧拆分) | 形状差异转形态键、多物体帧拆分 |
| [形态键动画序列导出](/theherta4/工具集/动画处理工具/形态键动画序列导出) | 导出形态键动画播放表 |
| [烘焙与自动导入](/theherta4/工具集/动画处理工具/烘焙与自动导入) | Alembic烘焙与导入 |
| [动画帧拆分](/theherta4/工具集/动画处理工具/动画帧拆分) | 将动画逐帧拆分为独立物体 |
| [自动化形态键导出](/theherta4/工具集/动画处理工具/自动化形态键导出) | 依赖SSMT的自动化形态键导出 |
| [动画导出与缓冲合并](/theherta4/工具集/动画处理工具/动画导出与缓冲合并) | 动画导出和顶点缓冲合并 |
