# 工具集

工具集是 TheHerta4 插件提供的辅助工具面板，包含大量用于 Blender 建模、绑骨、贴图处理和动画制作的实用工具。

工具集面板位于 Blender 3D 视口的侧边栏（N面板）中，在 `TheHerta4` 分类下。需要先开启"工具集模式"开关才能看到所有子面板。

## 工具分类

工具集按功能分为以下四大类：

| 分类 | 说明 |
|------|------|
| [顶点组处理工具](/theherta4/工具集/顶点组处理工具/顶点组处理工具介绍) | 顶点组的创建、重命名、清理、备份恢复和权重调整 |
| [骨骼与模型处理工具](/theherta4/工具集/骨骼与模型处理工具/骨骼与模型处理工具介绍) | 骨骼管理、权重传递、网格编辑、UV工具、场景清理、集合关联、修改器操作 |
| [贴图与材质工具](/theherta4/工具集/贴图与材质工具/贴图与材质工具介绍) | DDS转换、法线贴图生成、颜色烘焙、透明通道提取、光照模板、材质管理 |
| [动画处理工具](/theherta4/工具集/动画处理工具/动画处理工具介绍) | 形态键控制、Alembic烘焙导入、动画帧拆分、自动化导出 |
