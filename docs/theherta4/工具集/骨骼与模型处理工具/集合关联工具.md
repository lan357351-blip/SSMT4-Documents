# 集合关联工具

批量将物体和集合关联到指定目标集合中，或从目标集合中取消关联。

## 操作步骤

### 第1步：设置源项目

点击"添加选中项至列表"按钮，将当前选中的物体和活动集合添加到源列表中（自动去重）。

### 第2步：指定目标集合

选择要将源项目关联到的目标集合。

### 第3步：执行操作

- **执行关联**：将源列表中的所有集合和物体以"关联"方式添加到目标集合中（自动防止循环关联）
- **取消关联**：从目标集合中取消关联源列表中的所有集合和物体

## 效果

- 关联后，同一物体/集合的数据在多个集合中共享，不产生副本
- 取消关联后，物体仅从目标集合中移除，不会删除数据
