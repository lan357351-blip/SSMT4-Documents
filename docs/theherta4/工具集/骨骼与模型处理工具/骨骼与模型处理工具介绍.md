# 骨骼与模型处理工具

骨骼与模型处理工具（BMTP）提供了一系列用于骨骼管理、权重传递、网格编辑、UV管理、场景清理、集合关联和修改器操作的工具。

## 子面板列表

| 面板 | 说明 |
|------|------|
| [骨骼控制](/theherta4/工具集/骨骼与模型处理工具/骨骼控制) | 骨骼显示、清理、对齐、重命名 |
| [权重操作](/theherta4/工具集/骨骼与模型处理工具/权重操作) | 权重传递、平滑、扩散 |
| [模型控制](/theherta4/工具集/骨骼与模型处理工具/模型控制) | 顶点色设置 |
| [网格编辑](/theherta4/工具集/骨骼与模型处理工具/网格编辑) | 动态桥接、模型分割 |
| [UV数据工具](/theherta4/工具集/骨骼与模型处理工具/UV数据工具) | UV清理、重命名、批量添加 |
| [场景清理](/theherta4/工具集/骨骼与模型处理工具/场景清理) | 删除空网格、清理材质、清理折痕/锐边/法线 |
| [集合关联工具](/theherta4/工具集/骨骼与模型处理工具/集合关联工具) | 批量关联/取消关联集合 |
| [修改器工具](/theherta4/工具集/骨骼与模型处理工具/修改器工具) | 修改器应用、法线处理、批量操作 |
