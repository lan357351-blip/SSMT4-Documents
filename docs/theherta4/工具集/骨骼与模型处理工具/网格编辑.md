# 网格编辑

## 动态桥接循环边

在编辑模式下，对选中的两条循环边执行桥接操作，可桥接顶点数不同的循环边。

### 参数

| 参数 | 说明 |
|------|------|
| 分段数 | 桥接的分段数量 |
| 反转 | 是否反转桥接方向 |
| 平滑度 | 桥接的平滑程度 |

### 执行的操作

1. 进入编辑模式
2. 对选中的边执行 `bridge_edge_loops` 操作
3. 使用设定的分段数和平滑度

### 效果

- 两条循环边之间生成桥接面
- 适用于连接不同顶点数的网格边界

## 模型分割

提供三种模型分割方式：

### 根据UV松散块分割模型

按UV松散块将模型分割为多个独立物体，分割后的物体放入新集合中。

### 根据共享与孤立顶点组分割模型

先按松散块分割，再根据各块共享顶点组的情况进行合并——有交集的顶点组对应的物体会合并为一个。

### 根据顶点组将模型打碎为松散块

按顶点组分割选中物体的网格，每个顶点组对应的部分成为独立物体。
