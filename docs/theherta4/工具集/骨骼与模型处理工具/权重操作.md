# 权重操作

## 权重传递

从源物体向选中的目标物体传递顶点组权重。

### 参数

| 参数 | 说明 |
|------|------|
| 源物体 | 权重数据的来源物体 |
| 使用形态键位置 | 传递前先应用形态键位置 |
| 使用骨架位置 | 传递前先应用骨架修改器位置 |
| 仅传递选中组 | 只传递列表中勾选的顶点组 |
| 传递后清理 | 传递完成后清空目标物体的原有顶点组 |

### 执行的操作

1. 可选先应用骨架修改器和/或形态键的位置
2. 使用 Blender 的数据传递功能（NEAREST映射模式）进行反向权重传递
3. 可选仅传递选中的顶点组或全部顶点组
4. 传递后恢复物体的原始位置

### 效果

- 目标物体获得与源物体相同的顶点组权重分布
- 适用于拓扑不同但形状相似的物体之间的权重传递

## 权重平滑

对选中物体的顶点组权重进行平滑处理。

### 参数

| 参数 | 说明 |
|------|------|
| 平滑因子 | 每次平滑的强度 |
| 重复次数 | 平滑操作的重复次数 |

### 执行的操作

1. 切换到权重绘制模式
2. 对每个顶点组执行指定次数的平滑操作
3. 恢复原始模式

### 效果

- 权重分布更加平滑
- 减少权重突变区域

## 权重扩散

将有权重顶点的权重按邻居平均值扩散到相邻无权重顶点。

### 参数

| 参数 | 说明 |
|------|------|
| 迭代次数 | 扩散操作的迭代次数 |

### 执行的操作

1. 对每个无权重的顶点，计算其有权重邻居的平均权重
2. 将平均权重赋给该顶点
3. 归一化所有顶点的权重
4. 重复指定次数

### 效果

- 权重从有区域向无权重区域扩散
- 适用于扩展权重范围
