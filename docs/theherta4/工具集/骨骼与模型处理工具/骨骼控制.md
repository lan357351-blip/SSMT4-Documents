# 骨骼控制

## 显示使用的骨骼

隐藏骨架中未被任何顶点组引用的骨骼，只显示被使用的骨骼。

### 执行的操作

1. 查找选中网格物体关联的骨架
2. 收集所有被顶点组引用的骨骼名称
3. 隐藏未被引用的骨骼

### 效果

- 骨架中只显示被使用的骨骼
- 便于查看和编辑有效的骨骼结构

## 显示所有骨骼

取消骨架中所有骨骼的隐藏状态。

### 执行的操作

1. 获取活动骨架
2. 取消所有骨骼的隐藏状态

## 清理无效骨骼

删除骨架中未被任何顶点组引用的骨骼。

### 执行的操作

1. 查找绑定到活动骨架的所有网格物体
2. 收集所有顶点组名称
3. 进入骨架编辑模式
4. 删除未被任何顶点组引用的骨骼

### 效果

- 无效骨骼被彻底删除（而非隐藏）
- 骨架结构更加精简

## 局部轴向对齐

将骨架中每根骨骼的Y轴（主轴）对齐到指定的局部坐标轴方向。

### 参数

| 参数 | 说明 |
|------|------|
| 对齐轴 | 选择对齐到哪个局部轴（X/Y/Z） |

### 执行的操作

1. 进入骨架编辑模式
2. 对每根骨骼，计算其当前方向
3. 将骨骼Y轴旋转到指定局部轴方向
4. 保持骨骼长度不变，roll归零

## 重命名为索引

将骨架中所有骨骼按名称排序后重命名为数字索引，同步更新关联网格物体的顶点组名称。

### 执行的操作

1. 收集骨架中所有骨骼，按名称排序
2. 将每根骨骼重命名为数字索引（0, 1, 2, ...）
3. 同步更新所有关联网格物体的顶点组名称
4. 将映射关系（索引→原始名称）保存为JSON文本块

### 效果

- 骨骼名称变为纯数字索引
- 顶点组名称同步更新
- 映射关系保存到文本编辑器，可用于后续恢复

## 从映射表恢复

从JSON映射表文本块中读取索引到原始名称的映射，恢复骨骼和顶点组的原始名称。

### 参数

| 参数 | 说明 |
|------|------|
| 映射表文本 | 选择文本编辑器中保存的映射表 |

### 执行的操作

1. 读取指定文本块中的JSON映射数据
2. 进入骨架编辑模式
3. 按映射关系恢复骨骼原始名称
4. 同步更新关联网格物体的顶点组名称
