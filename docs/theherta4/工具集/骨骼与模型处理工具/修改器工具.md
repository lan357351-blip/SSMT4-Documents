# 修改器工具

## 修改器与法线

### 在有形态键的模型上应用修改器

Blender 原生不支持在含形态键的物体上应用修改器。此工具通过特殊方法解决该限制，弹出对话框让用户选择要应用的修改器。

### 平滑法线存UV（近似）

将平滑法线数据存储到UV通道中，用于游戏引擎中的轮廓线修复。

### 重命名骨骼（GI）（测试）

对原神解包的骨架执行一系列变换操作：清除缩放、镜像、应用变换，然后按顶点组排序重命名骨骼为数字索引。

### 法线重计算

| 功能 | 说明 |
|------|------|
| 向量归一化算法重计算TANGENT | 使用向量相加归一化算法重新计算TANGENT通道，用于轮廓线修复 |
| 算术平均归一化算法重计算COLOR | 使用算术平均归一化算法重新计算COLOR通道，用于崩坏3 2.0新角色轮廓线修复 |

## 修改器批量操作

### 骨架修改器 → 形态键

将选中网格物体的骨架修改器应用为形态键，新形态键值设为1.0，原修改器隐藏。

### 应用骨架修改器

批量应用选中物体的骨架修改器。含形态键的物体使用特殊方法处理，无形态键的直接应用。

### 应用全部形态键

批量移除选中物体的所有形态键，效果等同于将形态键应用到基础网格。

### 晶格修改器 → 形态键

将选中网格物体的晶格修改器应用为形态键，新形态键值设为1.0，原修改器隐藏。

### 按名称批量删除修改器

根据逗号分隔的名称列表，在所有选中物体中删除名称匹配的修改器。

### 按名称批量应用修改器

根据逗号分隔的名称列表，在所有选中网格物体中应用名称匹配的修改器。含形态键的物体使用特殊方法处理。

::: warning 镜像修改器
应用镜像修改器时，如果合并选项开启可能导致问题，请谨慎操作。
:::
