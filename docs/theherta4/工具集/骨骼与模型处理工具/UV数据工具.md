# UV数据工具

## UV清理

### 仅保留活动UV

删除除活动UV层以外的所有UV贴图。

### 按模式删除UV

根据正则表达式匹配UV名称，删除匹配的UV层。

### 参数

| 参数 | 说明 |
|------|------|
| 删除模式 | 正则表达式，匹配的UV层将被删除 |

## UV批量重命名

根据正则表达式匹配UV名称，将匹配的UV层按模板重命名。

### 参数

| 参数 | 说明 |
|------|------|
| 旧名称模式 | 正则表达式匹配UV名称 |
| 新名称模板 | 重命名模板，支持 `{index}` 占位符 |

## UV批量添加

为选中物体批量添加指定数量的UV层。

### 参数

| 参数 | 说明 |
|------|------|
| 添加数量 | 要添加的UV层数量 |
| 名称模板 | UV层命名模板，支持 `{index}` 占位符 |

### 执行的操作

1. 如果物体没有UV层，先创建默认的 `UVMap`
2. 按指定数量和名称模板添加新的UV层
