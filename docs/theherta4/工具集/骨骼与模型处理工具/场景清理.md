# 场景清理

## 场景清理工具

### 删除空网格

删除所有选中且没有面的网格物体（从场景和数据中彻底移除）。

### 删除松散点

删除选中物体中的松散顶点（不属于任何面的顶点）。

### 清理材质

清除所有选中物体的材质列表，然后执行孤立数据清除。

### 同步数据块名称

将选中物体的数据块名称（mesh data name）同步为与物体名称一致。

### 清理无效形态键

检测并删除所有顶点位置与基础形态键完全相同的形态键（阈值1e-6），然后清除孤立数据。

## 独立清理项目

### 材质清理

| 功能 | 说明 |
|------|------|
| 清理空材质槽 | 移除未指定材质的空槽位 |
| 清理重复材质 | 对同名材质只保留第一个出现的槽位 |

### 批量清理所有属性

一次性执行：顶点折痕归零、边线折痕归零、锐边改平滑、接缝取消、清除自定义拆边法向。

### 折痕清理

| 功能 | 说明 |
|------|------|
| 清理顶点折痕 | 将所有顶点折痕值归零 |
| 清理边线折痕 | 将所有边线折痕值归零 |

### 边线清理

| 功能 | 说明 |
|------|------|
| 清理锐边标记 | 将所有锐利边设为平滑 |
| 清理UV接缝标记 | 取消所有UV接缝标记 |

### 法线

| 功能 | 说明 |
|------|------|
| 清理自定义拆边法向 | 清除自定义拆分法线数据 |
