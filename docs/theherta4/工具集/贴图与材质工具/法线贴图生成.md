# 法线贴图生成

从高度图生成法线贴图，使用Sobel算子计算梯度。

## 生成参数

| 参数 | 说明 |
|------|------|
| 强度 | 法线贴图的强度系数 |
| 模糊半径 | 生成前的模糊半径（像素） |
| 蓝通道值 | 法线贴图蓝通道（Z分量）的固定值 |
| 反转 | 是否反转法线方向 |

## 材质选项

| 参数 | 说明 |
|------|------|
| 创建新材质 | 为生成的法线贴图创建新材质并连接节点 |
| 材质前缀 | 新材质的名称前缀 |

## 执行的操作

1. 遍历选中网格物体的材质
2. 找到第一个贴图节点作为高度图
3. 使用Sobel算子从高度图计算梯度
4. 根据梯度生成法线向量
5. 保存为PNG文件
6. 可选创建新材质并连接法线贴图节点

## 附加工具

| 功能 | 说明 |
|------|------|
| 反转法线贴图绿通道 | 将所有NormalMap贴图的绿色通道取反，用于不同引擎兼容 |
| 标准化法线贴图 | 将法线向量归一化为单位长度，确保法线贴图数据正确 |
