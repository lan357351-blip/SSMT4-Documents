# 透明通道提取

从贴图的Alpha通道提取透明信息，写入顶点色属性或创建透明材质。

## 提取设置

| 参数 | 说明 |
|------|------|
| 允许半透明 | 开启后保留半透明值，关闭后按阈值二值化 |
| 阈值 | 二值化阈值（不允许半透明时），Alpha值大于阈值的为1，否则为0 |

## 材质选项

| 参数 | 说明 |
|------|------|
| 创建透明材质 | 为提取的Alpha通道创建新材质 |
| 新材质前缀 | 新材质的名称前缀 |

## 执行的操作

1. 遍历选中物体的材质
2. 找到4通道（RGBA）贴图
3. 提取Alpha通道数据
4. 若不允许半透明，按阈值二值化
5. 将Alpha值写入顶点色属性（Color Attribute）
6. 可选创建新材质，将Alpha连接到BSDF的Alpha输入

## 效果

- 透明信息从贴图转移到顶点色
- 可选创建使用Alpha通道的透明材质
