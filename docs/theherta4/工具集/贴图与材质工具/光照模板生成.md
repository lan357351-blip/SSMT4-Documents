# 光照模板生成

为选中的网格物体创建LightMap和MaterialMap材质模板。

## 生成类型

| 选项 | 说明 |
|------|------|
| LightMap | 创建光照贴图材质模板 |
| MaterialMap | 创建材质贴图材质模板 |

## 应用模式

| 模式 | 说明 |
|------|------|
| 替换 | 清除原有材质，替换为新模板材质 |
| 追加 | 在原有材质基础上追加新模板材质 |

## 执行的操作

1. 为选中物体创建Principled BSDF + Image Texture节点组合的材质
2. 根据应用模式替换或追加材质

::: info 注意
此功能仅创建材质节点，不生成UV层。
:::
