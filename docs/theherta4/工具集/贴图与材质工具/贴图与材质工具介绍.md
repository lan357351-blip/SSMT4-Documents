# 贴图与材质工具

贴图与材质工具（TT）提供了DDS贴图转换、法线贴图生成、颜色烘焙、透明通道提取、光照模板生成和材质管理等功能。

## 依赖项

部分功能需要外部依赖：
- **Scipy**：法线贴图生成功能需要此库，可在面板中点击安装按钮
- **texconv.exe**：DDS转换功能需要微软的纹理转换工具，需放置到 Toolset 目录或手动指定路径
