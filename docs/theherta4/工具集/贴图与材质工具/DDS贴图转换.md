# DDS贴图转换

将Blender中的PNG/TGA等贴图批量转换为DDS格式，使用微软的 texconv.exe 工具。

## 转换工具配置

| 参数 | 说明 |
|------|------|
| texconv路径 | 手动指定texconv.exe路径（也可自动从Toolset目录或系统环境查找） |
| 删除原始文件 | 转换后删除原始的PNG/TGA文件 |

## 默认转换规则

| 贴图类型 | DDS格式 |
|---------|---------|
| DiffuseMap | bc7_unorm_srgb |
| NormalMap | r8g8b8a8_unorm |
| 其他 | bc7_unorm |

## 自定义转换规则

启用"使用自定义转换规则"后，可以添加、删除、测试转换规则。每条规则包含：

| 字段 | 说明 |
|------|------|
| 正则表达式 | 匹配贴图名称的模式 |
| DDS格式 | 匹配时使用的DDS压缩格式 |
| 启用 | 是否启用该规则 |

规则还支持保存为JSON文件和从JSON文件加载。

## 执行的操作

1. 遍历Blender中所有图片
2. 根据图片名称匹配DDS格式规则
3. 将图片保存为临时PNG文件
4. 调用texconv.exe将PNG转换为DDS
5. 可选删除原始文件
