# 材质预览与管理

为场景中的材质创建预览平面，方便查看和管理材质效果。

## 材质匹配设置

| 参数 | 说明 |
|------|------|
| 名称模式 | 正则表达式，匹配材质名称 |

## 全局设置

| 参数 | 说明 |
|------|------|
| 基础分辨率 | 预览平面的基础分辨率 |

## 功能列表

| 功能 | 说明 |
|------|------|
| 刷新材质列表 | 用正则匹配选中物体的材质，为每个匹配材质创建预览平面 |
| 清除所有预览 | 删除所有预览平面物体，清空预览列表 |
| 切换可见性 | 切换指定预览平面的可见/隐藏状态 |
| 选中平面 | 选中指定预览平面并设为活动对象 |
| 从平面更新UV | 根据预览平面的位置和缩放更新其UV坐标 |
| 烘焙贴图集 | 创建一张空白Atlas图片（基础框架） |

## 执行的操作（刷新材质列表）

1. 用正则表达式匹配选中物体的材质名称
2. 为每个匹配的材质创建一个预览平面（Plane）
3. 将材质赋予预览平面
4. 记录源物体信息到预览列表

## 效果

- 材质效果可以在3D视口中直观预览
- 便于对比不同材质的效果
