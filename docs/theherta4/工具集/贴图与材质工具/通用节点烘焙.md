# 通用节点烘焙

将材质节点网络烘焙为贴图，支持自定义分辨率规则。

## 烘焙设置

| 参数 | 说明 |
|------|------|
| 预览类型 | 平面/球/立方体/猴子 |
| 烘焙尺寸 | 默认烘焙分辨率 |
| 按UV展开顶点 | 将预览几何体按UV展开 |
| 节点类型 | 要烘焙的节点类型过滤 |
| 导入回材质 | 烘焙后将结果导入回材质节点 |

## 分辨率规则

启用"使用材质名称匹配分辨率"后，可以根据材质名称正则匹配使用不同的烘焙分辨率。

默认规则：
| 模式 | 分辨率 |
|------|--------|
| face | 4096 |
| body | 2048 |
| hair | 2048 |
| eye | 1024 |

## 执行的操作

1. 为选中物体的每个材质创建预览几何体
2. 将材质赋予预览几何体
3. 使用Cycles引擎Emit烘焙将材质颜色烘焙为PNG贴图
4. 可选将烘焙结果导入回材质节点

## 效果

- 复杂的节点网络被简化为单张贴图
- 输出文件名直接使用材质名
