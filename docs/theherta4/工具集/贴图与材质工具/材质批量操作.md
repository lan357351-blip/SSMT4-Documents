# 材质批量操作

提供材质的批量赋予、删除和重复材质合并功能。

## 材质批量操作

| 功能 | 说明 |
|------|------|
| 赋予材质 | 将指定材质追加到所有选中网格物体的材质槽中 |
| 删除材质 | 从所有选中网格物体中移除指定材质 |

## 清理重复材质

自动合并项目中所有使用相同贴图的材质。例如 `Mat` 和 `Mat.001` 如果使用相同的贴图，将合并为 `Mat`。

### 执行的操作

1. 按材质使用的贴图名称组合作为key分组
2. 将使用相同贴图的重复材质合并为第一个材质引用
3. 删除多余的材质数据块

### 效果

- 减少场景中的重复材质
- 统一材质引用，避免混乱
