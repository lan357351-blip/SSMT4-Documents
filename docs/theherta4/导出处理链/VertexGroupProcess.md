# 顶点组处理

VertexGroup Process（顶点组处理）节点用于在导出时对物体的顶点组执行批量操作。

## 节点信息

- **节点类型**：`SSMTNode_VertexGroupProcess`

## 功能说明

顶点组处理节点可以对物体的顶点组执行以下操作：

- **重命名**：根据映射表将顶点组名称从源名称替换为目标名称
- **合并**：将多个顶点组合并为一个
- **清理**：移除无权重或不需要的顶点组
- **填充**：为缺失的顶点组创建默认权重

## 节点参数

| 参数 | 说明 |
|------|------|
| Process Mode | 处理模式 |
| Fill Missing Groups | 是否填充缺失的顶点组（默认开启） |

## 处理模式

顶点组处理节点支持多种处理模式，通过映射表定义源顶点组名称到目标名称的转换关系。映射表可以来自：

1. **VertexGroup Match 节点**：通过 KD-Tree 和 Chamfer 距离自动匹配源物体和目标物体的顶点组
2. **VertexGroup Mapping Input 节点**：直接从文本编辑器中读取映射表

## 在处理链中的角色

顶点组处理节点在链路顺序执行阶段对物体执行实际的顶点组操作。如果同一条链路中还包含 Rename 节点，且 Rename 节点开启了"顶点组处理后再改名"，则顶点组处理会先于重命名执行。

## 执行统计

节点执行后会输出统计信息：
- **renamed**：重命名的顶点组数量
- **merged**：合并的顶点组数量
- **cleaned**：清理的顶点组数量
- **filled**：填充的顶点组数量
