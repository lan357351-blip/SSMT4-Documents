# 蓝图嵌套

Blueprint Nest（蓝图嵌套）节点用于在当前蓝图中引用另一个蓝图，实现蓝图的模块化和复用。

## 节点信息

- **节点类型**：`SSMTNode_Blueprint_Nest`

## 功能说明

蓝图嵌套节点允许将一个蓝图作为子模块嵌入到当前蓝图中。当处理链遍历到 Blueprint Nest 节点时，会进入引用的嵌套蓝图继续遍历，完成后再返回父蓝图。

## 节点参数

| 参数 | 说明 |
|------|------|
| Blueprint Name | 引用的蓝图名称，从已有的蓝图节点树中选择 |

## 嵌套蓝图的遍历

1. 当遍历到 Blueprint Nest 节点时，获取其引用的蓝图名称
2. 验证引用的蓝图是否存在且类型正确（`SSMTBlueprintTreeType`）
3. 检测循环引用（防止无限递归）
4. 进入嵌套蓝图，从其中的 Object Info 节点开始遍历
5. 到达嵌套蓝图的 Result Output 节点后，返回父蓝图
6. 从 Blueprint Nest 节点的输出连接继续遍历

## 嵌套深度

蓝图支持多层嵌套，即嵌套蓝图中的 Blueprint Nest 节点可以继续引用更深层的蓝图。系统通过循环引用检测确保不会出现无限递归。

## 在处理链中的角色

Blueprint Nest 节点在处理链中记录嵌套信息，嵌套蓝图中的 Object Info 节点会被收集并纳入主蓝图的处理链中。
