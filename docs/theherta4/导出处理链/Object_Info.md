# 物体信息

Object Info 是导出处理链的起始节点，用于指定要导出的 Blender 物体。

## 节点信息

- **节点类型**：`SSMTNode_Object_Info`
- **图标**：物体数据模式
- **最小宽度**：300

## 功能说明

Object Info 节点是蓝图中最基本的节点，它定义了导出流程的起点。每个 Object Info 节点对应一个 Blender 场景中的物体，该物体将作为处理链的输入，经过后续节点的处理后最终导出。

## 节点参数

| 参数 | 说明 |
|------|------|
| Object Name | 物体名称，可通过下拉列表选择或使用吸管工具从3D视图中拾取 |
| Object ID | 物体的内部指针ID（自动生成，用于跟踪物体引用） |
| Object Prefix | 物体名称前缀（自动解析，只读） |

### 自动解析的前缀信息

Object Info 节点会自动从物体名称中解析以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| DrawIB | 绘制调用索引缓冲区哈希 | `4c11c155` |
| IndexCount | 索引数量 | `288` |
| FirstIndex | 起始索引 | `7068` |
| Component | 组件标识 | - |
| Alias Name | 别名（前缀之后的部分） | `自定义名称` |

物体名称的格式通常为：`{DrawIB}-{IndexCount}-{FirstIndex}.{AliasName}`

## 操作按钮

- **吸管工具**：在3D视图中点击拾取物体
- **定位按钮**：在3D视图中选中并定位到该物体
- **刷新物体ID**：更新物体引用关联

## 在处理链中的角色

Object Info 节点是处理链的起点。正向解析从 Object Info 节点出发，沿输出连接遍历到 Generate Mod 节点，形成完整的处理链。

一个蓝图可以包含多个 Object Info 节点，每个节点对应一条独立的处理链。
