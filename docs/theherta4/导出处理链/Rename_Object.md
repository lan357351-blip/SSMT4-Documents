# 重命名物体

Rename Object 节点用于在导出过程中对物体名称进行字符串替换。

## 节点信息

- **节点类型**：`SSMTNode_Object_Rename`
- **图标**：大纲视图

## 功能说明

Rename Object 节点支持多条重命名规则，按顺序对物体名称执行字符串替换操作。这在需要修改导出物体名称以匹配游戏引擎命名规范时非常有用。

## 节点参数

| 参数 | 说明 |
|------|------|
| Rename Rules | 重命名规则列表，每条规则包含 Search（搜索字符串）和 Replace（替换字符串） |
| Reverse Mapping | 全局反转映射开关。开启后，所有规则执行完毕，会按反向顺序再执行一遍（search ↔ replace 互换） |
| 顶点组处理后再改名 | 延迟改名开关。开启后，当链路中存在顶点组处理节点时，重命名会在顶点组处理完成后再执行 |

## 重命名规则的执行

规则按列表顺序依次执行，每条规则对当前名称执行 `str.replace(search, replace)` 操作。

### 执行示例

假设物体名称为 `4c11c155-288-7068.旧名称`，规则为：
1. 搜索 `旧名称`，替换为 `新名称`
2. 搜索 `288`，替换为 `512`

执行结果：
- 规则 1：`4c11c155-288-7068.旧名称` → `4c11c155-288-7068.新名称`
- 规则 2：`4c11c155-288-7068.新名称` → `4c11c155-512-7068.新名称`

### 反转映射

开启反转映射后，在正向规则执行完毕后，会按反向顺序再执行一遍反转操作（将 replace 替换回 search）。这通常用于在导出时临时修改名称，但在最终配置中恢复原始名称的场景。

### 延迟改名

当链路中同时存在 Rename 节点和顶点组处理节点时，通常需要先执行顶点组处理（因为顶点组名称可能依赖物体名称）。开启"顶点组处理后再改名"后，Rename 节点的重命名操作会被延迟到顶点组处理完成后再执行。

## 同名冲突处理

如果重命名后的名称与场景中已有物体同名，系统会自动在名称中插入数字序号解决冲突，例如：
- `4c11c155-288-7068.名称_copy` → `4c11c155-288-7068.001.名称_copy`

## 在处理链中的角色

Rename 节点在处理链遍历时记录重命名历史（`rename_history`），在链路顺序执行阶段实际修改物体名称。重命名操作会更新处理链的 `object_name`，并建立原始名称到新名称的映射关系。
