# 生成Mod

Generate Mod 节点是蓝图的输出节点，也是导出操作的入口。

## 节点信息

- **节点类型**：`SSMTNode_Result_Output`
- **图标**：导出
- **宽度**：400

## 功能说明

Generate Mod 节点是蓝图的终点，所有处理链最终都会汇聚到这个节点。它提供了导出操作的触发按钮和各种导出选项。

## 导出选项

### 通用选项

| 选项 | 说明 |
|------|------|
| 禁止自动贴图流程 | 不自动生成贴图相关的 INI 配置 |
| 向量归一化法线存入 TANGENT | 将归一化后的法线向量存入 TANGENT 通道（全局） |
| 生成分支架构 Mod 面板 | 生成支持分支架构的 Mod 面板（测试中） |
| 生成 Mod 后打开文件夹 | 导出完成后自动打开 Mod 所在文件夹 |
| 使用指定生成 Mod 文件夹路径 | 使用自定义的导出目录 |

### 游戏特定选项

不同游戏模式会显示不同的选项：

| 游戏 | 选项 |
|------|------|
| WWMI | 忽略静音形态键、应用所有修改器、导出时添加缺失顶点组 |
| HIMI | 算术平均归一化法线存入 COLOR |
| ZZMI | 使用 ZZMI 槽位修复 |
| GIMI | 使用 ORFix |
| EFMI | 使用 RabbitFX 槽位 |

### 顶点去重精度控制

展开后可以配置参与去重的数据类型：
- POSITION、NORMAL、TANGENT、BINORMAL
- TEXCOORD、COLOR
- BLENDWEIGHT、BLENDINDICES

## 输入输出

- **输入口**：动态数量的输入口（`Group 1`、`Group 2`、...），用于连接处理链
- **输出口**：`Post Process` 端口，用于连接后处理节点链

## 动态输入口

输入口数量会自动增减：
- 当最后一个输入口被连接时，自动添加新的输入口
- 当最后两个输入口都未连接时，自动移除最后一个

## 在处理链中的角色

Generate Mod 节点是处理链的终点。当遍历到达该节点时，处理链被标记为"已到达输出"（`reached_output = True`），只有到达输出的处理链才会参与最终的导出。
