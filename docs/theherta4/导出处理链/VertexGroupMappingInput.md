# 映射表输入

VertexGroup Mapping Input（映射表输入）节点用于直接输入顶点组的映射关系。

## 节点信息

- **节点类型**：`SSMTNode_VertexGroupMappingInput`
- **图标**：文本
- **最小宽度**：300

## 功能说明

映射表输入节点允许用户直接从 Blender 文本编辑器中选择一个映射表文本，作为顶点组处理的输入。这适用于已知源顶点组和目标顶点组名称对应关系的场景。

## 节点参数

| 参数 | 说明 |
|------|------|
| Mapping Text | 映射表文本，选择文本编辑器中的文本 |
| Target Hash | 目标哈希标识，物体名称以"哈希-"开头时匹配，留空则应用于所有物体 |

## 映射表格式

映射表文本的格式为每行一条映射规则，使用 `=` 分隔源名称和目标名称：

```
# 注释行（以 # 或 // 开头）
源顶点组名称 = 目标顶点组名称
左臂 = L_Arm
右臂 = R_Arm
身体 = Body
```

- 空行和以 `#` 或 `//` 开头的注释行会被忽略
- 每行只能包含一条映射规则
- 源名称和目标名称两端的空格会被自动去除

## 在处理链中的角色

映射表输入节点在处理链中记录映射信息（`vertex_group_mapping_nodes`），其映射结果会传递给 VertexGroup Process 节点使用。

Target Hash 参数允许针对特定物体应用不同的映射表。当物体名称以指定的哈希值开头时，该映射表才会生效。
