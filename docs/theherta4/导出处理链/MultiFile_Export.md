# 多文件导出

MultiFile Export（多文件导出）节点用于支持自动切换多个物体进行多次导出，常用于动画帧导出。

## 节点信息

- **节点类型**：`SSMTNode_MultiFile_Export`
- **图标**：文件夹
- **最小宽度**：350

## 功能说明

多文件导出节点维护一个物体列表，导出时会按列表顺序依次将每个物体作为当前导出对象，执行多次导出操作。每次导出使用不同的 Buffer 文件夹名称，生成独立的导出文件。

## 节点参数

### 物体列表

节点维护一个有序的物体列表，每个列表项包含：

| 字段 | 说明 |
|------|------|
| Object Name | 物体名称 |
| Object ID | 物体的内部指针ID |
| Original Object Name | 原始物体名称 |
| Draw IB | 从名称解析的 DrawIB 哈希 |
| Index Count | 从名称解析的索引数量 |
| First Index | 从名称解析的起始索引 |
| Alias Name | 别名 |

### 动画拆分参数

| 参数 | 说明 |
|------|------|
| Split Start Frame | 动画拆分的起始帧 |
| Split End Frame | 动画拆分的结束帧 |
| Split Use Precise Mode | 高精度模式，逐帧跳转确保动画准确性 |
| Split Set Linear | 线性插值，将关键帧插值设为线性防止过冲 |

## 操作按钮

| 按钮 | 说明 |
|------|------|
| 解析合集 | 解析 Blender 合集中的所有物体（识别 `_001`、`_002` 等序列），自动添加到列表 |
| 检查顶点数 | 统计列表中每个物体的顶点数，确保所有物体顶点数一致 |
| 拆分选中物体动画 | 对选中物体进行动画拆分，拆分后的物体自动添加到列表 |
| 上移/下移 | 调整物体在列表中的顺序 |
| 移除 | 从列表中移除物体 |

## 动画拆分

动画拆分功能会将一个带动画的物体按帧拆分为多个静态物体：
1. 从起始帧到结束帧逐帧遍历
2. 每帧评估物体的变形结果
3. 将每帧的网格数据创建为独立物体
4. 物体命名格式为 `{原始名称}_{帧号:03d}`
5. 拆分后的物体自动隐藏并添加到导出列表

## 物体名称解析

多文件导出节点会自动从物体名称中解析 DrawIB、IndexCount、FirstIndex 等信息：
- 格式 `Hash-Count-Index.别名`：解析为 DrawIB=Hash, IndexCount=Count, FirstIndex=Index, Alias=别名
- 格式 `Hash-Count-Index`：解析为 DrawIB=Hash, IndexCount=Count, FirstIndex=Index

## 在处理链中的角色

多文件导出节点在正向解析时作为起始节点之一，其物体列表中当前导出索引对应的物体会被作为处理链的输入。导出次数由所有多文件导出节点中最大的列表长度决定。
