# 顶点组匹配

VertexGroup Match（顶点组匹配）节点用于自动匹配源物体和目标物体的顶点组。

## 节点信息

- **节点类型**：`SSMTNode_VertexGroupMatch`

## 功能说明

顶点组匹配节点使用 **KD-Tree 预筛选 + Chamfer 距离精确匹配** 的算法，自动将源物体的顶点组映射到目标物体的顶点组。

### 匹配算法

1. **获取顶点位置**：提取物体所有顶点的世界坐标
2. **构建点云**：为每个顶点组收集其影响的所有顶点位置
3. **KD-Tree 预筛选**：计算每个顶点组点云的质心，构建 KD-Tree 进行快速近邻搜索
4. **Chamfer 距离匹配**：对 KD-Tree 筛选出的候选顶点组，计算双向 Chamfer 距离进行精确匹配
5. **阈值过滤**：只保留 Chamfer 距离低于阈值的匹配结果

### Chamfer 距离

Chamfer 距离是一种衡量两个点云相似度的指标，计算方式为：
- 对于点云 A 中的每个点，找到点云 B 中最近的点，计算距离
- 对于点云 B 中的每个点，找到点云 A 中最近的点，计算距离
- 取所有距离的平均值

距离越小，两个点云越相似。

## 节点参数

| 参数 | 说明 |
|------|------|
| Match Mode | 匹配模式 |
| Candidates Count | KD-Tree 预筛选的候选数量（默认 3） |
| Chunk Size | 分块计算的大小，避免内存溢出（默认 256） |

## 在处理链中的角色

顶点组匹配节点在处理链中记录映射信息（`vertex_group_mapping_nodes`），其匹配结果会传递给 VertexGroup Process 节点使用。
