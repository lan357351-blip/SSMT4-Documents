# 组

Group 节点是一个纯分组节点，用于将多个物体归类到同一个组中。

## 节点信息

- **节点类型**：`SSMTNode_Object_Group`
- **图标**：组

## 功能说明

Group 节点不执行任何实际处理操作，它仅用于逻辑分组。可以将多个 Object Info 节点或其他节点的输出连接到 Group 节点的输入，然后将 Group 节点的输出连接到下游节点。

## 特性

- **动态输入口**：输入口数量会自动增减。当最后一个输入口被连接时，会自动添加新的输入口；当最后两个输入口都未连接时，会自动移除最后一个
- **查看递归解析预览**：点击节点上的按钮可以在3D视图中预览该组包含的所有物体（使用局部视图模式）

## 在处理链中的角色

Group 节点在处理链中记录分组信息（`group_stack`），但不修改物体数据。它主要用于：
- 组织蓝图结构，使节点图更清晰
- 将相关物体归类，便于管理
