# 资源合并

资源合并后处理节点通过计算贴图文件内容的 MD5 哈希值，自动合并内容相同的资源引用并删除重复的贴图文件。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_ResourceMerge`
- **标签**：资源合并

## 功能说明

在导出过程中，不同的物体可能引用了内容相同但文件名不同的贴图。资源合并节点通过计算文件内容的 MD5 哈希值来识别这些重复资源，将它们合并为同一个资源引用，并删除多余的贴图文件。

## 工作流程

1. **扫描贴图文件**：遍历导出目录中的所有贴图文件
2. **计算 MD5 哈希**：对每个贴图文件的内容计算 MD5 哈希值
3. **识别重复**：将哈希值相同的文件标记为重复
4. **更新引用**：在 INI 配置文件中，将重复资源的引用更新为保留的那个资源
5. **删除重复文件**：删除被合并的重复贴图文件

## 对文件的操作

### INI 配置修改

- 扫描所有 INI 文件中的 `filename` 字段
- 将重复资源的文件路径替换为保留资源的路径

### 文件删除

- 删除内容相同但文件名不同的贴图文件
- 只保留每组重复文件中的一个

## MD5 哈希计算

节点使用分块读取的方式计算文件哈希，避免大文件导致内存溢出：
- 块大小：65536 字节（64KB）
- 算法：MD5
