# 后处理

后处理是导出流程的最后阶段，在模型数据导出完成后执行。后处理节点对生成的文件和配置表进行修改、优化和补充。

## 后处理链的连接方式

后处理节点通过 **Post Process** 端口连接到 Generate Mod 节点。Generate Mod 节点有一个专用的 `Post Process` 输出端口，后处理节点通过 `SSMTSocketPostProcess` 类型的端口串联。

后处理节点的执行顺序由它们在链路中的连接顺序决定，从 Generate Mod 的 Post Process 端口开始，沿连接方向依次执行。

## 后处理节点列表

TheHerta4 蓝图版提供以下后处理节点：

| 节点 | 说明 |
|------|------|
| [形态键配置](/theherta4/后处理/形态键配置) | 生成支持多形态叠加混合的 INI 配置 |
| [材质转资源](/theherta4/后处理/材质转资源) | 根据场景物体的材质和纹理创建资源引用 |
| [资源合并](/theherta4/后处理/资源合并) | 通过 MD5 哈希自动合并内容相同的资源 |
| [缓冲区清理](/theherta4/后处理/缓冲区清理) | 扫描并删除未被引用的 .buf 文件 |
| [多文件配置](/theherta4/后处理/多文件配置) | 为指定物体生成多文件动画配置 |
| [血量检测](/theherta4/后处理/血量检测) | 追加血量检测模块（仅限 ZZZ） |
| [滑块面板](/theherta4/后处理/滑块面板) | 为形态键参数生成可交互的滑块 UI |
| [顶点属性定义](/theherta4/后处理/顶点属性定义) | 为形态键和多文件配置提供顶点属性定义 |

## 执行流程

1. 从 Generate Mod 节点的 Post Process 输出端口开始
2. 沿后处理链路收集所有未被静音的后处理节点
3. 按连接顺序依次调用每个节点的 `execute_postprocess` 方法
4. 每个节点接收 Mod 导出路径作为参数，对导出目录中的文件进行操作

## 备份机制

大多数后处理节点在修改文件之前会创建累积备份，确保原始文件不会丢失。备份文件命名格式为 `{文件名}.bak.{序号}`。
