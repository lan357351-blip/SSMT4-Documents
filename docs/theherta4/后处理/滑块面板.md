# 滑块面板

滑块面板后处理节点用于为形态键参数生成可交互的滑块 UI 配置。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_Slider`
- **标签**：滑块面板

## 功能说明

该节点在导出的 INI 配置中添加滑块面板定义，允许用户在游戏内通过滑块实时调整形态键的强度值。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 滑块列表 | 滑块定义列表，每个滑块关联一个形态键参数 | 空 |

### 滑块列表项

每个滑块项包含以下字段：

| 字段 | 说明 |
|------|------|
| 参数名 | 关联的形态键参数名称 |
| 显示名称 | 滑块面板中显示的名称 |
| 最小值 | 滑块的最小值 |
| 最大值 | 滑块的最大值 |
| 步长 | 滑块的步进值 |

## 对文件的操作

### INI 配置追加

节点会在 INI 文件中追加滑块面板相关的配置段落，包括：
- 滑块定义和参数绑定
- 数值范围和步长设置
