# 多文件配置

多文件配置后处理节点用于为指定哈希值的物体生成多文件动画配置，支持紧凑缓冲区和顶点增量存储。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_MultiFile`
- **标签**：多文件配置

## 功能说明

该节点在导出完成后，为多文件导出的物体生成动画切换的 INI 配置。它将多个导出文件组织为可切换的动画帧序列，支持紧凑缓冲区存储和顶点增量优化。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 哈希值 | 需要处理的哈希值，多个用逗号分隔 | 空 |
| 循环参数名 | 用于动画帧切换的参数名称 | `$swapkey100` |
| 激活参数名 | 用于控制动画执行的参数名称 | `$active0` |
| 使用紧凑缓冲区 | 仅存储变化的顶点数据（需要 numpy） | 开启 |
| 存储顶点增量 | 存储与基础模型的差值（需要 numpy） | 开启 |

## 对文件的操作

### INI 配置生成

节点会在 INI 文件中生成以下配置：

- **Constants 段**：声明循环参数和激活参数
- **KeySwap 段**：定义动画帧切换的快捷键和条件
- **TextureOverride 段**：为每个动画帧定义渲染覆盖

### 紧凑缓冲区

当启用"使用紧凑缓冲区"时，节点会：
1. 读取基础帧和目标帧的顶点数据
2. 比较两帧之间的差异，只存储发生变化的顶点
3. 生成紧凑的 .buf 文件，大幅减小文件体积

### 顶点增量存储

当同时启用"存储顶点增量"时：
- 不存储目标帧的完整顶点坐标
- 而是存储目标帧与基础帧的差值
- 进一步减小 .buf 文件体积

## 动画帧切换逻辑

节点生成的 INI 配置实现了以下动画切换逻辑：

1. **激活参数**控制动画是否执行（`$active0 == 1` 时执行）
2. **循环参数**控制当前显示的动画帧（`$swapkey100` 的值对应帧索引）
3. 按下快捷键时，循环参数自动递增，切换到下一帧
