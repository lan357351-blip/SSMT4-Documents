# 缓冲区清理

缓冲区清理后处理节点用于扫描并删除配置表路径下所有未被任何 INI 文件引用的 .buf 文件。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_BufferCleanup`
- **标签**：缓冲区清理

## 功能说明

在导出过程中，可能会生成一些不再需要的 .buf 缓冲区文件（例如经过资源合并后变得多余的文件）。缓冲区清理节点会扫描导出目录，找出所有未被 INI 文件引用的 .buf 文件并删除它们。

## 工作流程

1. **扫描 INI 文件**：遍历导出目录中的所有 INI 文件，提取 `filename` 字段引用的文件路径
2. **收集引用文件**：将所有被引用的文件路径归入引用集合
3. **扫描 .buf 文件**：递归遍历导出目录中的所有 .buf 文件
4. **识别未引用文件**：将不在引用集合中的 .buf 文件标记为未引用
5. **删除未引用文件**：删除所有未引用的 .buf 文件

## 对文件的操作

### INI 文件扫描

节点会解析所有 INI 文件中匹配 `^\s*filename\s*=\s*(.+)` 模式的行，提取被引用的文件路径。

### 文件删除

- 删除所有未被任何 INI 文件 `filename` 字段引用的 .buf 文件
- 支持递归扫描子目录
