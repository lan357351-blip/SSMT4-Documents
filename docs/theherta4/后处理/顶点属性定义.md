# 顶点属性定义

顶点属性定义后处理节点用于为形态键和多文件配置提供顶点属性定义。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_VertexAttrs`
- **标签**：顶点属性定义

## 功能说明

该节点在导出的 INI 配置中添加顶点属性定义段落，指定形态键和多文件动画中使用的顶点数据格式和布局。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 顶点属性列表 | 顶点属性定义列表 | 空 |

### 顶点属性列表项

每个属性项包含以下字段：

| 字段 | 说明 |
|------|------|
| 语义名称 | 顶点属性的语义名称（如 POSITION、NORMAL、TEXCOORD 等） |
| 语义索引 | 语义索引 |
| 格式 | 数据格式（如 R32G32B32_FLOAT、R32G32_FLOAT 等） |
| 输入槽位 | 输入槽位索引 |

## 对文件的操作

### INI 配置追加

节点会在 INI 文件中追加顶点属性定义相关的配置段落，包括：
- 顶点布局描述
- 输入槽位映射
