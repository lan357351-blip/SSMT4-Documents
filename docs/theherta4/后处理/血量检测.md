# 血量检测（仅限ZZZ）

血量检测后处理节点用于在 INI 配置中追加血量检测模块，仅限 ZZZ（绝区零）使用。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_Health`
- **标签**：血量检测

## 功能说明

该节点在导出的 INI 配置中追加血量检测相关的段落，使 Mod 能够根据游戏内角色的血量状态自动切换模型表现。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| Health IB Hash | 血量检测对应的 IB 哈希值 | 空 |
| Health First Index | 血量检测对应的起始索引 | 0 |
| Health Index Count | 血量检测对应的索引数量 | 0 |

## 对文件的操作

### INI 配置追加

节点会在 INI 文件中追加血量检测相关的配置段落，包括：
- 检测特定 DrawCall 的渲染调用
- 根据血量状态切换模型或材质
