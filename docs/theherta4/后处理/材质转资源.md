# 材质转资源

材质转资源后处理节点用于根据场景物体的材质和纹理创建资源引用。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_Material`
- **标签**：材质转资源

## 功能说明

该节点扫描导出目录中的 INI 文件，根据场景物体的材质和纹理信息，在 INI 配置中创建对应的资源引用段落。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 覆盖现有资源 | 如果资源已存在，是否覆盖 | 关闭 |
| 材质切换变量 | 用于材质切换的起始变量名（会自动递增） | `$swapkey150` |

## 对文件的操作

### INI 配置修改

节点会在 INI 文件中添加以下内容：

- **Resource 段**：为每个纹理创建资源引用，指定纹理文件路径
- **TextureOverride 段**：为每个材质创建纹理覆盖配置
- **Constants 段**：声明材质切换变量

### 材质切换变量

材质切换变量用于在游戏中动态切换材质。变量名从 `material_switch_var` 指定的起始名称开始自动递增，例如：
- `$swapkey150`
- `$swapkey151`
- `$swapkey152`
