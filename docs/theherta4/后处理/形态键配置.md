# 形态键配置

形态键配置后处理节点用于读取分类文本，生成支持多形态叠加混合的 INI 配置。

## 节点信息

- **节点类型**：`SSMTNode_PostProcess_ShapeKey`
- **标签**：形态键配置

## 功能说明

该节点在导出完成后，根据蓝图中收集的形态键信息生成 INI 配置文件。支持多形态键的叠加混合，并提供多种优化选项以减小文件体积和提升运行时性能。

## 节点参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 使用紧凑缓冲区 | 仅存储变化的顶点数据，大幅减小体积（需要 numpy） | 开启 |
| 存储顶点增量 | 不存储完整顶点坐标，而是存储与基础模型的差值（需要 numpy） | 开启 |
| 优化查找性能 | 使用顶点 FREQ 索引缓冲区替代大量条件分支，显著提升 GPU 性能（需要 numpy） | 开启 |

## 对文件的操作

### 生成的 INI 配置

节点会在导出目录的 INI 文件中追加形态键相关的配置段落，包括：

- **Constants 段**：声明形态键强度变量（`$Freq_` 前缀）
- **TextureOverride 段**：为每个形态键变体定义渲染覆盖
- **Present 段**：形态键的条件渲染逻辑

### 生成的缓冲区文件

根据优化选项，节点会生成不同格式的 `.buf` 文件：

- **紧凑缓冲区**（`use_packed_Meshess`）：仅存储与基础模型不同的顶点数据
- **顶点增量**（`store_deltas`）：存储顶点坐标与基础模型的差值而非完整坐标
- **优化查找**（`use_optimized_lookup`）：生成 FREQ 索引缓冲区，替代 INI 中的大量条件分支

## 形态键分类报告

节点执行前会自动生成形态键分类报告（写入 Blender 文本编辑器的 `Shape_Key_Classification` 文本块），内容包括：
- 原始物体与衍生物体的映射关系
- 每个形态键槽位对应的物体列表
