# 插件联动

插件联动部分介绍 TheHerta4 蓝图版与其他插件的协作功能。目前主要支持与 **Bone Palette** 插件的联动。

## Bone Palette 导出

Bone Palette 导出节点是终末地 EFMI 专用的节点，用于在导出时将骨骼调色板数据本地化到物体上。

## 节点信息

- **节点类型**：`SSMTNode_BonePaletteExport`
- **图标**：骨骼数据
- **最小宽度**：350

## 功能说明

Bone Palette 导出节点在导出处理链中执行骨骼调色板的本地化操作。在 EFMI（终末地）中，骨骼调色板（Bone Palette）定义了骨骼到调色板槽位的映射关系。该节点将全局的骨骼调色板数据转换为物体本地的调色板数据，确保导出的模型在游戏中能正确渲染。

## 节点参数

| 参数 | 说明 |
|------|------|
| Bone Palette Name | 骨骼调色板名称，从场景中的骨骼调色板数据中选择 |

## 对物体执行的操作

### 1. 骨骼调色板本地化

节点执行时会对物体执行以下操作：

1. **查找骨骼调色板**：根据节点中指定的名称查找对应的骨骼调色板数据
2. **验证物体**：确认物体有骨骼数据（Armature 修改器或父级骨骼）
3. **复制物体**：创建物体的副本，副本命名添加 `_BPE` 后缀
4. **应用本地化**：将全局骨骼调色板映射应用到物体副本上

### 2. 顶点组处理

骨骼调色板本地化过程中，节点会对物体的顶点组执行以下操作：

1. **读取调色板映射**：从骨骼调色板数据中读取骨骼名称到调色板槽位的映射
2. **重命名顶点组**：将物体的顶点组名称重命名为调色板槽位名称
3. **清理无用顶点组**：移除不在调色板映射中的顶点组
4. **填充缺失顶点组**：为调色板中存在但物体中缺失的骨骼创建默认权重的顶点组

### 3. 物体名称变化

经过 Bone Palette 导出节点处理后，物体名称会发生变化：
- 原始名称：`Body_copy`
- 处理后名称：`Body_BPE_copy`

`_BPE` 后缀表示该物体已经过 Bone Palette 导出处理。

## 在处理链中的角色

Bone Palette 导出节点在链路顺序执行阶段对物体执行骨骼调色板本地化操作。处理完成后：
- 物体被替换为本地化后的副本
- 处理链的 `object_name` 更新为带有 `_BPE` 后缀的名称
- 顶点组数据被更新为调色板槽位格式

## 前置条件

使用 Bone Palette 导出节点需要：
1. 场景中存在有效的骨骼调色板数据（通过 Bone Palette 插件创建）
2. 物体有骨骼绑定（Armature 修改器或父级骨骼）
3. 当前游戏模式为 EFMI
